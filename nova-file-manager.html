About Nova File Manager

Nova File Manager gives you full access to your device's filesystem in a clean, modern interface — browse folders, manage installed APKs, and keep your storage tidy, all without any of your files ever leaving your phone.

Built-in tools like duplicate and large-file finders, an empty-folder cleaner, and a recycle bin for safe deletion make it easy to reclaim storage space, while OTG and network storage support extend it beyond just your internal storage.

Features

What it does

Full Filesystem Browser

Browse, move, rename and manage files and folders anywhere on your device.

APK Manager

List, install and share installed and stored APK files.

Duplicate & Large File Finder

Quickly spot the files eating up your storage space.

Zip / Unzip Archives

Create and extract archives directly within the app.

Recycle Bin

Deleted files go to a recycle bin first, so mistakes are easy to undo.

OTG & Network Storage

Browse USB-OTG drives and network storage alongside local files.

Permissions & Privacy

Nova File Manager needs broad storage/file access to perform its core job of managing your files, plus access to your list of installed apps for its APK manager feature — a sensitive permission we only use for that purpose. It also uses notifications and internet access, which is used only for ads.

See the full Privacy Policy entry for this app for a complete breakdown of permissions and third-party services.
